OleoFlow Quemadura

Batch tracking, complete traceability, and QR code generation for the olive debittering process.

OleoFlow est une application mobile conçue pour les producteurs et les prestataires de service de désamérisation (quemadura). Elle permet de gérer chaque lot d'olives de la réception jusqu'à la livraison finale, avec une traçabilité complète et des outils adaptés au terrain, même sans connexion Internet.

OleoFlow es una aplicación móvil diseñada para productores y proveedores de servicios de desamargado (quemadura). Permite gestionar cada lote de aceitunas desde la recepción hasta la entrega final, con trazabilidad completa y herramientas adaptadas al terreno, incluso sin conexión a Internet.

OleoFlow is a mobile application designed for producers and debittering service providers (quemadura). It manages each olive batch from reception to final delivery, with full traceability and tools adapted for the field, even without Internet connection.

Funcionalidades principales

Key features

Formulaires de suivi

Saisie chronologique des étapes clés : injection caustique, rinçages, contrôles, ajouts d'ingrédients, mesures Baumé. Chaque entrée est horodatée et signée.

Formularios de seguimiento

Registro cronológico de las etapas clave: inyección cáustica, enjuagues, controles, adición de ingredientes, mediciones Baumé. Cada entrada lleva fecha, hora y operador.

Tracking forms

Chronological recording of key steps: caustic injection, rinses, checks, ingredient additions, Baumé measurements. Each entry is timestamped and signed.

QR codes intelligents

Génération automatique d'un QR code contenant toutes les données du lot. Structure optimisée pour rester lisible même avec beaucoup d'informations.

Códigos QR inteligentes

Generación automática de un código QR con todos los datos del lote. Estructura optimizada para mantener la legibilidad incluso con mucha información.

Smart QR codes

Automatic generation of a QR code containing all batch data. Optimized structure to remain readable even with large amounts of information.

Rapports PDF multilingues

Export du dossier de lot complet en PDF, dans la langue de l'utilisateur (FR/ES/EN). Idéal pour les contrôles qualité et les clients.

Informes PDF multilingües

Exportación del expediente completo del lote en PDF, en el idioma del usuario (FR/ES/EN). Ideal para controles de calidad y clientes.

Multilingual PDF reports

Export complete batch file as PDF, in the user's language (FR/ES/EN). Ideal for quality controls and customers.

Mode hors ligne

Fonctionne parfaitement dans les zones sans réseau. Les données sont synchronisées dès qu'une connexion est disponible.

Modo sin conexión

Funciona perfectamente en zonas sin red. Los datos se sincronizan automáticamente cuando hay conexión disponible.

Offline mode

Works perfectly in areas with no network. Data syncs automatically when a connection is available.

Interface multilingue

Bascule instantanée entre le français, l'espagnol et l'anglais. Tous les libellés, messages et rapports suivent la langue choisie.

Interfaz multilingüe

Cambio instantáneo entre español, francés e inglés. Todas las etiquetas, mensajes e informes se adaptan al idioma seleccionado.

Multilingual interface

Instant switch between English, French, and Spanish. All labels, messages, and reports follow the selected language.
